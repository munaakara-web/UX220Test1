Tim Berners Lee's original plan for the wirld wide web

Tim Berners Lee never intended on the world wide web being as large as it was it was intended to be a small closed off oproduct for a couple of physicists to use. As opposed to the billions of users that log on to the world wide web daily, many pages are no longer static documents but interactable websites personalized to the user. Though the base of it all still funtions on Sir Lee's core inventions in the World Wide Web.

What changed from Tim Berners Lee's Plan

Firstly the population that has access to the world wide web has grown massiely since its ideation phase. The world wide web has changed to be more fluid and frequently changes on a user to user basis. What started as a place to share text and documents became a place for commerce media and social interaction Berners lee built the framework for every modern website but what he could not imagine was the scale and the possibilities that the world wide web would open to us.
