Tim Berners Lee: The inventor of the Web and his key inventions on the way to creating the web

Tim Berners Lee had multiple key inventions on his way to inventing the world wide web, He created Html which is the base for most websites to date. He created Url the main method of finding things on the web,even creating http which is the way web browsers and servers are able to interact. He then built and published the first web browser building the framework for all web design moving forward
